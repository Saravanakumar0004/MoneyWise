# 💰 MoneyWise - MERN Finance Tracker

## Quick Start

### 1. Backend
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```

### 3. Open: http://localhost:5173

## Features
- ✅ User Auth (JWT)
- ✅ Income Tracking
- ✅ Expense Tracking  
- ✅ Investment Portfolio
- ✅ P&L Calculator
- ✅ Dashboard Charts
- ✅ Month Filter
